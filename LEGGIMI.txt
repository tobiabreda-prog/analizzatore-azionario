COME OTTENERE L'APK (senza installare nulla sul PC)
1. Crea un account gratuito su github.com e un nuovo repository PRIVATO.
2. Carica tutto il contenuto di questa cartella (compresa la cartella .github) nel repository
   (Add file > Upload files, trascina i file, Commit).
3. Solo quando tutte le modifiche sono concluse e integrate nel branch main: Actions > Android debug APK > Run workflow > main.
   L'APK NON viene piu' compilata automaticamente a ogni modifica del codice.
4. A fine build apri l'esecuzione e scarica l'artefatto "analizzatore-azionario-debug-apk": estrai lo ZIP per ottenere app-debug.apk.
5. Prima di installare verifica la compatibilita' della firma con l'app gia' installata (vedi docs/ANDROID_SIGNING_MIGRATION.md); salva una copia dei dati. Quindi installa l'APK sul telefono.
6. Nell'app tocca l'icona della chiave e inserisci una chiave Gemini da Google AI Studio. Usa un progetto SENZA fatturazione collegata: l'app usa solo gemini-3.5-flash-lite e non attiva Search grounding.
7. Alpha Vantage è facoltativo: la chiave gratuita consente fino a 25 richieste/giorno; la cache locale evita chiamate ripetute. FRED richiede una chiave API gratuita; ECB non richiede chiave. Yahoo Finance non richiede chiave ma usa endpoint non ufficiali.

In alternativa, con Android Studio + JDK 17:  npm install && npm run build && npx cap add android && npx cap sync android && node scripts/generate-android-icons.mjs
poi Build > Build APK(s) in Android Studio.

TEST: npm install && npm test  (la build dell'APK esegue i test e si ferma se falliscono).
STRUTTURA: src/scoring.js (punteggi, etichetta, livelli), src/fundamentals.js, src/analysts.js,
src/providers/ (Alpha Vantage, FRED, ECB, SEC adapter; Yahoo Finance in src/data.js), src/lib/ (utilita', indicatori, formati), tests/.

ATTENZIONE: I workflow Android hanno ancora una firma debug non necessariamente stabile fra i due percorsi. Per gli aggiornamenti in-place seguire docs/ANDROID_SIGNING_MIGRATION.md e gestire la PR #34 prima della pubblicazione finale.
